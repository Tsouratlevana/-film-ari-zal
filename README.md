# Film — L'histoire du Rav Ari (Ari Zal)

Court-métrage animé racontant l'histoire du Rav Ari, réalisé avec Higgsfield.

## Cadre du projet

| Élément | Choix |
|---|---|
| Durée visée | 5 minutes |
| Style | Anime réaliste, rendu sérieux, « tout dans la sainteté » |
| Ton | Conte mystique |
| Format | 16:9 |
| Narration | Français, sans accent |
| Habillage | Sous-titres incrustés + miniature |

## Organisation du dépôt

| Dossier | Contenu |
|---|---|
| [`script/`](script/script.md) | Le récit découpé en scènes, avec la narration |
| [`storyboard/`](storyboard/storyboard.md) | La liste des plans dans l'ordre : durée, cadrage, action |
| [`prompts/`](prompts/) | Un fichier par scène avec le prompt exact de chaque plan Higgsfield |
| [`bible-visuelle/`](bible-visuelle/bible.md) | Les règles fixes : personnages, décors, style, voix |
| [`suivi/`](suivi/suivi.md) | Avancement des plans et crédits dépensés |

Les vidéos et images ne sont pas stockées ici (trop lourdes pour GitHub) : elles restent dans Higgsfield. Ce dépôt garde le texte et les références qui permettent de les régénérer.
