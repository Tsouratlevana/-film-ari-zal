# Storyboard

Liste des plans dans l'ordre du film. Un plan = une génération vidéo Higgsfield.

Identifiant d'un plan : `S<scène>-P<plan>`, par exemple `S1-P2` (scène 1, plan 2).

| Plan | Scène | Durée | Cadrage | Action | Narration associée | Statut |
|---|---|---|---|---|---|---|
| S1-P1 | 1 | | | | | à faire |

## Statuts

- **à faire** : pas encore généré
- **généré** : une version existe, pas encore validée
- **à refaire** : version rejetée, noter pourquoi dans `suivi/suivi.md`
- **validé** : version retenue pour le montage
